Connect with an admin key

Paste an API key with the admin scope. This page keeps it in this tab's session storage only, so it is forgotten when the tab closes, and sends it only to this engine. Browse the other demo pages with a listen or edit key instead (API key… in the page menu).

No admin key? On first start tr-engine prints one to its log (stderr). You can always create one on the host:
tr-engine keys create --name "admin" --scopes admin
In Docker: docker compose exec -T tr-engine tr-engine keys create --name "admin" --scopes admin
The bootstrap admin key is still active. It was printed to the engine's log on first start. Create a named admin key for yourself, connect with it, then revoke the key named bootstrap admin.
